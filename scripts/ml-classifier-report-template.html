二、ROC 曲线

图 1：4 算法 5-fold CV 的 ROC 曲线对比。横轴=1-特异度（假正率 FPR），纵轴=灵敏度（真正率 TPR）。AUC 越接近 1 越好。

如何解读：

  • AUC：0.5=随机猜，0.7-0.8=尚可，0.8-0.9=良好，>0.9=优秀
  • 关注曲线左上角 - 越靠近左上角，模型在不同阈值下整体表现越好
  • 若多算法 AUC 接近，选更简单的模型（奥卡姆剃刀）：LR > SVM > RF > XGBoost
  • 类别不平衡时 ROC 可能虚高，需结合 PR 曲线判断

三、特征重要性

图 2：4 算法特征重要性对比。不同算法用不同指标衡量重要性（LR=系数绝对值，SVM=权重，RF=Gini 重要性，XGBoost=Gain）。

如何解读：

  • 排名靠前的特征 -> 对模型决策贡献最大
  • 多算法一致靠前 -> 特征重要性稳健
  • 不同算法排序差异大 -> 模型视角不同，建议结合 SHAP 做更细粒度解释
  • 注意：树模型（RF/XGBoost）的重要性是模型内在的，SHAP 提供更严谨的博弈论解释

五、下游分析建议

  1. SHAP 解释 - 将 model.rds 传给 shap-explain 工具，获得博弈论级别的特征重要性解释
  2. 外部验证 - 在独立队列上验证最优模型的泛化能力
  3. 超参调优 - 如需进一步提升，可手动调整 caret 网格搜索范围
  4. 临床转化 - 选定模型后，计算每个样本的预测概率，结合临床数据评估实用性
  5. 避免泄漏 - 确保特征选择在训练集内完成，CV 评估时特征选择应在每折内重做
注意：模型选择原则 若多算法 AUC 差距 <0.02，优先选择更简单、更可解释的模型。复杂模型（XGBoost）在小样本上易过拟合，AUC 高不代表泛化好。

六、方法学说明（可用于论文 Methods）

Four machine learning algorithms were compared using the
caret package in R: logistic regression (LR), support vector
machine (SVM), random forest (RF), and XGBoost. Models were
evaluated using 5-fold cross-validation, repeated 3 times,
with the area under the ROC curve (AUC) as the optimization
metric. All features were pre-processed with centering,
scaling, and Yeo-Johnson transformation. The best-performing
model was saved as an RDS object for downstream SHAP analysis.
