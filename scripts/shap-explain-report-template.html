一、分析概览

本报告对上游 ML 分类器（ml-classifier）训练好的模型进行 SHAP 可解释性分析。SHAP（SHapley Additive exPlanations）基于博弈论的 Shapley 值，为每个样本的每个特征分配一个贡献值，既能解释全局特征重要性，又能解释单样本决策逻辑，是当前最严谨的模型解释方法。

SHAP vs 传统特征重要性
  • 传统重要性（RF Gini / XGBoost Gain）：模型内在指标，无法分解到单样本
  • SHAP：基于 Shapley 值，每个样本的每个特征都有贡献值，局部+全局统一
  • 本工具用 Kernel SHAP（iml 包）：模型无关方法，通用但比 TreeSHAP 慢

二、全局 SHAP 重要性

图 1：全局 SHAP 特征重要性。按所有样本 SHAP 绝对值均值排序，反映每个特征对模型预测的整体贡献。

如何解读：

  • 排名靠前的特征 -> 对模型决策贡献最大
  • SHAP 值是 方向性 的（正/负），而 Gini/Gain 只有大小
  • 与 ml-classifier 的特征重要性对比：若排序一致 -> 特征重要性稳健；若不一致 -> SHAP 更可信

三、SHAP Beeswarm 图

图 2：SHAP Beeswarm 图。每行一个特征，每个点代表一个样本。横轴=SHAP 值（正=推向正类，负=推向负类），颜色=特征值高低（红高蓝低）。

如何解读：

  • 红色点分布在右侧 -> 该特征值高时推向正类预测
  • 红色点分布在左侧 -> 该特征值高时推向负类预测（保护因子）
  • 点的横向散布宽 -> 该特征对不同样本影响差异大
  • 点都集中在 0 附近 -> 该特征对预测几乎无影响
  • 这是 SHAP 最核心的可视化，能同时看到重要性、方向和分布

四、单样本 Force Plot

图 3：单样本 SHAP Force Plot。展示某一样本从基线（base value）到预测值的过程中，各特征如何推动预测向正类或负类。

如何解读：

  • 红色（向右）= 推向正类预测的特征
  • 蓝色（向左）= 推向负类预测的特征
  • 条形长度 = 该特征对本次预测的贡献大小
  • 最终预测值 = 基线 + 所有 SHAP 值之和
  • 用于解释"模型为什么把这个样本预测为正/负类"

五、Dependence Plot

图 4：Top N 特征的 SHAP Dependence Plot。横轴=特征值，纵轴=SHAP 值，揭示特征值与模型预测间的非线性关系。

如何解读：

  • 正相关趋势 -> 特征值升高推向正类
  • 负相关趋势 -> 特征值升高推向负类
  • 非单调曲线 -> 存在阈值效应或非线性交互
  • 颜色散点 -> 隐含与另一特征的交互作用

七、方法学说明（可用于论文 Methods）

SHAP (SHapley Additive exPlanations) values were computed
using the iml package in R, which implements model-agnostic
Kernel SHAP. The upstream classifier (trained via the
ml-classifier tool) was passed as the prediction function.
Global feature importance was computed as the mean absolute
SHAP value across all samples. Local explanations were
visualized as force plots for individual samples. Dependence
plots were generated for the top N features to reveal
non-linear effects and interactions.
