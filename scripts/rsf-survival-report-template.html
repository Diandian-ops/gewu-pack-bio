一、分析概览

本报告对随机生存森林（Random Survival Forest, RSF）的建模结果进行解读。RSF 是一种非线性生存分析方法，能捕捉传统 Cox 模型难以发现的变量间交互效应和非线性关系，适用于高维基因组数据的预后建模。通过 OOB（Out-Of-Bag）估计和独立验证集评估模型的判别力。

C-index 解读标准
  • 0.5 = 随机预测（无判别力）

二、时间依赖 ROC

图 1：时间依赖 ROC 曲线。展示模型在 1 年、3 年、5 年时间点的判别能力。AUC 随时间变化反映模型预测能力的衰减情况。

如何解读：

  • 短期（1 年）AUC 通常最高 -> 近期预测更准
  • 若长期（5 年）AUC 仍保持 >0.7 -> 模型具有长期稳定判别力
  • AUC 随时间快速下降 -> 模型仅对近期预后有效
  • 与 Cox 模型对比：RSF 的非线性优势在复杂交互数据中更明显

三、VIMP 变量重要性

图 2：变量重要性（VIMP）排序。基于 OOB 置换误差计算，VIMP>0 表示该特征对预测有正贡献，值越大越重要。

如何解读：

  • VIMP 排名靠前的特征 -> 对生存预测贡献最大的变量
  • VIMP 接近 0 -> 该特征对模型几乎无贡献
  • VIMP 为负 -> 置换后反而提升预测，可能引入噪声，建议剔除
  • 与 Cox p 值对比：VIMP 衡量的是模型内在贡献，p 值是统计显著性，二者互补

四、部分依赖图

图 3：Top N 特征的部分依赖图。展示单一特征值变化时，模型预测风险（Mortality）如何变化，揭示非线性效应。

如何解读：

  • 曲线上升 -> 该特征值升高时死亡风险增加
  • 曲线下降 -> 该特征值升高时风险降低（保护因子）
  • 非单调曲线（如 U 型）-> 存在阈值效应，低和高值都有风险
  • 与 Cox 线性假设对比：若部分依赖曲线明显非线性，说明 Cox 会低估该特征的作用

七、下游分析建议

  1. 与 LASSO Cox 对比 - 若已用 lasso-cox 建模，对比二者 C-index，判断线性 vs 非线性模型谁更适合你的数据
  2. 外部验证 - 在独立队列上计算 risk score 并验证分层效果
  3. Nomogram 构建 - 若需临床可解释性，基于 RSF 选出的 top 特征构建 Cox nomogram
  4. 生物学解释 - 对 VIMP top 基因做通路富集，理解其生物学意义
  5. 注意过拟合 - OOB C-index 远高于 test C-index 时，考虑减少特征数或增大 nodesize
注意：RSF vs Cox 的选择 样本量 <100 或事件数 <30 时，RSF 易过拟合，建议优先用 Cox/LASSO Cox。RSF 优势在样本充足且存在复杂非线性交互时才能体现。

八、方法学说明（可用于论文 Methods）

A Random Survival Forest (RSF) was built using the
randomForestSRC package in R, with 500 trees, logrank
splitting rule, and default mtry (sqrt of total features).
Out-of-bag (OOB) error estimation was used for internal
validation. Variable importance (VIMP) was computed via
permutation. Time-dependent ROC curves at 1, 3, and 5
years were generated using the timeROC package. Patients
were stratified into high/low-risk groups by the median
RSF risk score, and compared using Kaplan-Meier curves
with log-rank test.
