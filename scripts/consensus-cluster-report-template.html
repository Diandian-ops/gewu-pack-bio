一、分析概览

本报告对 Consensus Clustering 的结果进行解读。共识聚类通过多次重采样（subsampling）+ 重复聚类 + 投票共识，评估聚类结果的稳定性，是肿瘤亚型发现的金标准方法。本工具遍历 k=2 到 max_k，自动选择最优 k 并验证聚类质量。

最优 k 选择策略
  • Δarea 法：计算 CDF 曲线下面积的相对变化（delta area），选择曲线趋于平缓的拐点
  • Silhouette 法：选轮廓系数最高的 k
  • 二者交叉验证，取共识。生物意义也需考虑（如已知亚型数）

二、CDF 累积分布图

图 1：共识矩阵的 CDF（累积分布函数）图。展示不同 k 值下共识值的分布。曲线越陡峭（集中在 0/1 两端），聚类越稳定。

如何解读：

  • 曲线集中在 0 和 1 附近（陡峭 S 型）-> 样本对聚类归属高度确定
  • 曲线平缓过渡 -> 存在大量"模糊"样本，聚类不稳定
  • 随 k 增大，CDF 曲线应逐渐变陡（更稳定），但 k 过大会过拟合

三、Δarea 图（最优 k 选择）

图 2：Delta area 图。横轴=k，纵轴=CDF 面积的相对变化量。曲线趋于水平时的 k 即"拐点"，再加 k 收益递减。

如何解读：

  • 曲线在某个 k 后明显变平缓 -> 该 k 为最优（再加一个亚型收益不大）
  • 若无明显拐点 -> 聚类结构不强，数据可能无明显亚型
  • 结合 Silhouette 和生物学意义综合判断

四、一致性矩阵热图

图 3：各 k 值的一致性矩阵热图。每个格子颜色表示两样本被分到同一簇的频率（0-1）。理想状态下对角线方块为深红（=1），方块外为白色（=0）。

如何解读：

  • 清晰方块：对角线上有明显的深色方块 -> 聚类稳定
  • 模糊边界：方块边界有渐变 -> 部分样本归属不确定
  • 噪点：方块外仍有零星深色 -> 噪声或过渡态样本
  • 选定的最优 k 对应的矩阵应呈现最清晰的方块结构

五、Silhouette Score

图 4：各 k 值的 Silhouette 轮廓系数。衡量每个样本与其所属簇的紧密程度，范围 [-1, 1]，越大越好。

如何解读：

  • Silhouette > 0.5 -> 聚类结构良好
  • 0.25-0.5 -> 结构较弱但可接受
  • <0.25 -> 聚类结构不明显
  • 若某 k 值 Silhouette 突然下降 -> 可能出现了不合理的亚型划分

六、PCA 亚型投影

图 5：PCA 二维投影，按亚型着色。直观展示各亚型在主成分空间中的分离程度。

如何解读：

  • 各亚型点团明显分离 -> 亚型间差异大，聚类有效
  • 亚型有重叠 -> 部分样本特征相近，需结合其他证据
  • PC1/PC2 解释方差比例低 -> 数据维度高，二维投影信息有限

八、下游分析建议

  1. 亚型间差异分析 - 用 deseq2 / 差异分析比较各亚型的特征基因差异
  2. 生存分析 - 用 km-survival 工具比较各亚型的预后差异，验证亚型临床意义
  3. 富集分析 - 对各亚型 marker 基因做 go-kegg / gsea 富集，理解亚型生物学特征
  4. 有监督建模 - 将亚型作为 label，用 ml-classifier 训练分类器，用于新样本亚型预测
  5. 多组学整合 - 若有多层组学，可用 mo-snf / mo-mofa 做多组学联合聚类，验证亚型跨组学一致性
注意：无监督聚类的局限 Consensus Clustering 是探索性方法，"最优 k"是数学上的拐点，不一定有生物学意义。必须结合生存差异、marker 基因、已有文献等多维度验证亚型的真实性和临床意义。

九、方法学说明（可用于论文 Methods）

Consensus clustering was performed using the
ConsensusClusterPlus package in R. The expression matrix was
subsamplingd at 80% (pItem=0.8) with 50 repetitions (reps=50)
for each k from 2 to max_k. Hierarchical clustering (hc) with
Pearson distance was used as the cluster algorithm. The
optimal k was determined by the delta area method (relative
change in CDF area) and validated by silhouette scores.
Sample-to-subtype assignments were extracted from the
consensus matrix at the optimal k.
