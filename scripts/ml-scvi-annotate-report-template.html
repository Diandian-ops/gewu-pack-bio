一、分析概览

本报告对 scVI（single-cell Variational Inference）的分析结果进行解读。scVI 是一种基于变分自编码器（VAE）的深度学习方法，通过学习细胞的低维潜空间表示，消除批次效应并进行聚类。与传统的 PCA 降维相比，scVI 能更好地处理 dropout 和计数数据的特性。

scVI 方法说明
  • VAE 架构：编码器将高维基因表达压缩到低维潜空间，解码器重构原始数据
  • 负二项分布：scVI 假设数据服从 NB 分布，适合 scRNA-seq 的 count 特性
  • 批次校正：如有 batch 信息，scVI 可在潜空间中自动校正批次效应
  • 下游聚类基于 scVI latent representation 的 kNN 图 + Leiden

三、训练曲线

图 2：scVI 训练 ELBO（证据下界）曲线。ELBO 上升并趋于平稳 -> 模型收敛。
  • ELBO 上升后趋于平稳 -> 模型收敛，训练正常
  • ELBO 未收敛（仍在上升）-> 可考虑增加 epochs
  • ELBO 震荡剧烈 -> 学习率可能过高或 batch size 过小
  • early stopping 会在 ELBO 不再改善时自动停止训练

五、下游建议

  1. 差异表达 - 基于 scVI latent 的聚类做 marker 基因鉴定
  2. 细胞注释 - 对 Leiden 聚类做生物学注释（marker / 参考映射）
  3. 批次评估 - 如有 batch 信息，用 kBET / iLISI 评估批次校正效果
  4. 模型迁移 - scvi_model 可用于 SCANVI 做有监督注释或新数据映射
注意：scVI vs PCA 的选择 scVI 在细胞数 >10000、dropout 严重或存在批次效应时优势明显。小数据集（<3000 细胞）上 VAE 易过拟合，传统 PCA 可能更稳定。
