一、分析概览

本报告对 Similarity Network Fusion (SNF) 的分析结果进行解读。SNF 将多个组学层各自构建的样本相似性网络融合为一个统一网络，再基于融合网络做谱聚类发现亚型。与 MOFA2 的因子分解不同，SNF 是聚类导向的多组学整合方法，直接输出亚型划分。

SNF vs MOFA2 的区别
  • SNF：网络融合 -> 谱聚类，直接输出亚型，适合"我要分几类"
  • MOFA2：因子分解 -> 连续因子得分，需后续聚类，适合"我要理解结构"
  • 建议二者都跑，对比亚型一致性，增强结论可信度

二、融合网络热图

图 1：融合后的样本相似性网络热图。对角线方块代表亚型，方块内越红（接近 1）表示样本越相似，方块外越白（接近 0）表示亚型间差异越大。

如何解读：

  • 清晰方块：对角线上有明显的深色方块 -> 聚类稳定，亚型间分离好
  • 模糊边界：方块边界有渐变 -> 部分样本归属不确定
  • 与单一组学层的网络对比：融合网络应比任何单一层更清晰（整合了多组学信息）

五、下游分析建议

  1. 生存分析 - 用 km-survival 比较各亚型的预后差异
  2. 差异分析 - 用 deseq2 比较各亚型的特征基因差异
  3. 多方法对比 - 与 mo-mofa + consensus-cluster 的亚型结果对比，计算 NMI/ARI
  4. 有监督建模 - 将亚型作为 label，用 ml-classifier 训练亚型预测器
  5. 生物学注释 - 对各亚型 marker 基因做富集分析
注意：SNF 参数敏感性 SNF 对超参数 K（邻居数）和 alpha（相似性超参）较敏感。默认 K=20, alpha=0.5 适用于大多数情况，但小样本（<50）建议降低 K。若结果不稳定，可尝试参数网格搜索。

六、方法学说明（可用于论文 Methods）

Similarity Network Fusion (SNF) was performed using the SNFtool
package in R. For each omics layer, a sample-by-sample distance
matrix was computed and converted to a status matrix to build
an affinity network. The networks were fused with K=20 (number
of neighbors), alpha=0.5 (hyperparameter), and T=20 iterations.
Spectral clustering on the fused network identified sample
subtypes. The optimal number of clusters (k) was determined
by the eigen-gap heuristic. If ground-truth labels were
provided, NMI and ARI were computed for validation.
