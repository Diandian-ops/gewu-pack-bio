一、分析概览

本报告对 5 种特征选择方法的结果进行对比解读。特征选择是机器学习建模前的关键步骤，旨在从高维特征中筛选出与表型最相关的变量子集，降低维度灾难、提升模型泛化能力、增强可解释性。本工具采用"多方法共识"策略：只有被多种独立方法共同选中的特征才进入最终候选池，降低单一方法偏差。

5 种方法对比
  • Variance filter：无监督粗筛，按方差排序，保留变异大的特征
  • Univariate Wilcoxon：单变量统计检验，逐特征评估组间差异显著性
  • mRMR：最大相关-最小冗余，兼顾特征与标签的相关性和特征间冗余度
  • Boruta：基于随机森林的 wrapper 方法，与随机影子特征比较显著性
  • RFE：递归特征消除，基于逻辑回归逐步剔除最不重要特征

二、5 法共识 Venn 图

图 1：5 种特征选择方法交集 Venn 图。每个椭圆代表一种方法选出的 Top N 特征集合，重叠区域为多种方法共同选中的特征。

如何解读：

  • 中心交集（5/5）：所有方法一致选中 -> 最稳健的候选特征，优先纳入下游建模
  • 4/5 交集：高度共识，仅次于 5/5
  • 3/5 交集：中等共识，可作为备选
  • 仅 1 法选中：单一方法特异性结果，可能是该方法偏好导致，谨慎使用
  • 共识策略：推荐使用至少 3/5 方法选中的特征作为最终特征集

三、单因素火山图

图 2：单因素 Wilcoxon 检验火山图。横轴=效应量（log2FC 或 AUC），纵轴=-log10(p)，虚线为显著性阈值。红色=显著上调，蓝色=显著下调，灰色=不显著。

如何解读：

  • 位于左上/右上角（显著且效应量大）的特征 -> 组间差异最大的特征
  • 此图为单变量视角，未考虑特征间冗余，需结合 mRMR/Boruta 综合判断

四、方法间相关性热图

图 3：5 种方法排序结果 Spearman 相关性热图。衡量不同方法对同一批特征的重要性排序是否一致。

如何解读：

  • 高相关（>0.7）：两种方法排序高度一致，说明特征重要性排序稳健
  • 低相关（<0.3）：两种方法视角差异大，互补性强，共识策略价值更高
  • 若所有方法相关性都很高，说明特征信号很强；若都较低，说明需依赖共识策略

六、下游分析建议

  1. ML 分类器建模 - 将 consensus_top_n.csv 导入 ml-classifier 工具，用 LR/SVM/RF/XGBoost 建模并评估
  2. LASSO Cox 预后 - 如有生存数据，将候选特征导入 lasso-cox 构建 prognosis signature
  3. SHAP 解释 - 建模后用 shap-explain 工具做特征重要性解释，验证特征选择结果
  4. 生物学验证 - 对共识特征进行文献调研，确认其与疾病的已知关联
  5. 注意过拟合 - 特征选择应在训练集内完成，避免信息泄漏到测试集
注意：避免数据泄漏 特征选择必须仅在训练集上进行，然后用选出的特征在测试集上评估。若在全数据集上做特征选择再分割 train/test，会导致信息泄漏和过拟合。

七、方法学说明（可用于论文 Methods）

Five feature selection methods were compared to identify
robust biomarkers. (1) Variance filter: top-N features by
variance. (2) Univariate Wilcoxon rank-sum test with BH
correction (p < 0.05). (3) mRMR (maximum relevance minimum
redundancy). (4) Boruta (RF-based wrapper, p < 0.01). (5) RFE
with logistic regression. A consensus score was computed as
the number of methods selecting each feature (range 0-5).
Features selected by ≥3 methods were retained as the final
feature set.
