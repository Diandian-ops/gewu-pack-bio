Seurat 单细胞标准流程

工具版本：Seurat v5 · 报告模板 v1.0 · 生成于 BioF3 在线分析平台

一、分析概览

本工具按 Seurat 官方 PBMC 3k tutorial 标准流程，对单细胞 RNA-seq 数据完成质控、降维、聚类与 marker 鉴定。所有可调参数的默认值均跟随官方教程。

{{n_markers}}
Marker 总数
关键参数 物种 = {{species}} · PCA dims = 1:{{dims_used}} · 聚类 resolution = {{resolution}} · 高变基因数 = {{n_variable}}
本工具不做什么 整合（Integration / Harmony / RPCA）、SCTransform、空间组学、轨迹分析（pseudotime / RNA velocity）、自动细胞类型注释、doublet 检测。这些功能留给后续专门工具。

二、质控（QC）

按官方 PBMC 3k tutorial 标准对每个细胞计算三项指标：基因数 (nFeature_RNA)、UMI 总数 (nCount_RNA) 和线粒体基因比例 (percent.mt)。

图 1：每个细胞的三项 QC 指标分布。检查左右两端的离群细胞。
图 2：UMI 数 vs 线粒体比例 / nFeature 的散点图。线性相关性反映数据质量。

三、高变基因（HVG）

使用 FindVariableFeatures(selection.method="vst", nfeatures={{n_variable}}) 选取前 N 个高变基因作为后续降维的输入。下方图标记 top 10 高变基因。

图 3：vst 方法挑出的高变基因（红色），前 10 个标记基因名。

四、降维与聚类

对所有高变基因执行 PCA，选取前 {{dims_used}} 个主成分构建 k-NN 图，再以 resolution = {{resolution}} 进行 Louvain 聚类，最后用 UMAP 可视化。

图 4：PCA 二维投影（未着色）。
图 5：ElbowPlot，辅助判断保留多少个 PC。本工具默认 1:{{dims_used}}。
图 6：PC1 / PC2 top loading 基因。
图 7：UMAP 按 seurat_cluster 着色，共 {{n_clusters}} 个 cluster。

五、Marker 基因

对每个 cluster 跑 FindAllMarkers(only.pos=TRUE)，选出 top N marker 用于 heatmap、violin、feature 可视化。

图 8：每个 cluster top marker DoHeatmap。
图 9：top 6 marker 跨 cluster VlnPlot。
图 10：top 6 marker 在 UMAP 上的 FeaturePlot。

六、解读与下一步

当前结果（{{n_clusters}} 个 cluster / {{n_markers}} 个 positive marker）已可作为后续细胞类型注释工具（SingleR / celltypist）、轨迹分析（monocle3）、通讯分析（CellChat）等的输入。
